AWS Research
Brief Overview

Amazon Web Services (AWS) was launched by Amazon in 2006, making it the earliest and currently the largest public cloud provider by market share. AWS offers a broad catalog of on-demand computing, storage, database, networking, and AI/ML services that let organizations build and scale applications without owning physical hardware. It is widely used by startups, enterprises, and government agencies alike.

Global Infrastructure

AWS's global infrastructure spans dozens of geographic Regions, each made up of multiple isolated Availability Zones (AZs) — physically separate data centers with independent power, cooling, and networking, connected by low-latency links. This design lets customers run highly available, fault-tolerant applications by distributing workloads across AZs. AWS also operates Local Zones and Wavelength Zones to bring compute closer to end users for lower latency, and a global network of edge locations for content delivery (via CloudFront).

Cloud Management Console

AWS is managed through the AWS Management Console (console.aws.amazon.com), a web-based dashboard where users can provision, configure, and monitor services. It organizes resources by service and region, and supports role-based access, billing dashboards, and the AWS CLI/SDKs for programmatic access outside the console.

Four (4) Core Services
Amazon EC2 (Elastic Compute Cloud) – resizable virtual servers for running applications.
Amazon S3 (Simple Storage Service) – scalable object storage for files, backups, and static content.
Amazon RDS (Relational Database Service) – managed relational databases (MySQL, PostgreSQL, etc.).
Amazon VPC (Virtual Private Cloud) – isolated virtual networks for securely connecting AWS resources.
Three (3) Advantages
Largest and most mature service catalog of any cloud provider, covering compute, storage, AI/ML, IoT, and more.
Extensive global infrastructure footprint, giving customers more region/AZ choices for latency and compliance.
Strong ecosystem and community — the most third-party tools, documentation, and hiring pool of AWS-skilled talent.
Typical Enterprise Use Cases

AWS is commonly chosen by startups needing to scale quickly without upfront infrastructure investment, as well as large enterprises running mission-critical workloads that need maximum service breadth and global reach (e.g., media streaming, e-commerce, and large-scale data processing).
