# Cloud Provider Comparison

This document compares the core infrastructure services offered by the three 
leading public cloud providers: Amazon Web Services (AWS), Microsoft Azure, 
and Google Cloud Platform (GCP).

## Service Comparison Table

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---------------------------|-----|------------------|------------------------|
| Compute | EC2 (Elastic Compute Cloud) | Virtual Machines | Compute Engine |
| Storage | S3 (Simple Storage Service), EBS | Blob Storage, Managed Disks | Cloud Storage, Persistent Disk |
| Networking | VPC (Virtual Private Cloud) | Virtual Network (VNet) | VPC (Virtual Private Cloud) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Cloud IAM |

## Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**

AWS is generally recognized as offering the broadest range of services, with 
over 200 fully featured services spanning compute, storage, databases, 
machine learning, IoT, and more. As the first major public cloud provider, 
it has had the longest time to expand its service catalog and build out 
niche offerings for nearly every use case.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**

Microsoft Azure would be the best fit for an organization already invested 
in Microsoft products. Azure offers seamless integration with tools like 
Windows Server, Active Directory, Microsoft 365, and .NET applications, 
which reduces compatibility issues and often qualifies for licensing 
discounts through existing Microsoft agreements.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**

Google Cloud Platform (GCP) is widely recognized for AI/ML and Kubernetes. 
Google created and open-sourced Kubernetes, and GCP's Vertex AI and 
TensorFlow integration make it a strong choice for machine learning 
workloads and container orchestration at scale.

**4. What similarities did you observe among the three cloud providers?**

All three providers offer equivalent core infrastructure categories — 
compute, storage, networking, and IAM — even though the specific product 
names differ. Each also provides pay-as-you-go pricing, global data center 
availability, auto-scaling capabilities, and strong security/compliance 
certifications, reflecting a shared set of foundational principles across 
the cloud computing industry.
